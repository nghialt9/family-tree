UI Components & API Endpoints

Các thành phần Vue và REST API của backend

🎨 Frontend Components

FamilyTreeCanvas.vue
VueFlow canvas toàn màn hình. Tự tính layout từ dữ liệu DB. Zoom/pan/collapse nhánh. Tạo 2 loại node + 2 loại edge.
PersonNode.vue
Node rich card kiểu C. Ảnh avatar, họ tên, ngày sinh, SĐT, badge thế hệ, nút "Chi tiết". Click mở PersonDrawer.
SpouseConnector.vue
Node ẩn (invisible) ở giữa 2 vợ chồng. Con cái kết nối xuống từ điểm này. Edge ngang có icon 💍.
PersonDrawer.vue
Side panel trượt ra từ phải. Ảnh lớn, tiểu sử đầy đủ, danh sách con cái, link vợ/chồng, nút Sửa (admin only).
PersonForm.vue
Modal thêm/sửa người. Upload ảnh, chọn cha/mẹ, chọn vợ/chồng từ danh sách. Admin only.
LoginPage.vue
Nhập SĐT → gọi API → nhận JWT → lưu localStorage → redirect về cây.

⚙️ REST API Endpoints

AUTH
POST /api/auth/login
body: {phone} → JWT token + role
PERSONS (viewer+)
GET /api/persons
GET /api/persons/:id
GET /api/persons/:id/relatives
PERSONS (admin only)
POST /api/persons
PUT /api/persons/:id
DELETE /api/persons/:id
POST /api/persons/:id/avatar
RELATIONSHIPS (admin only)
POST /api/relationships
DELETE /api/relationships/:id
TREE
GET /api/tree
→ toàn bộ nodes + edges đã tính sẵn
cho VueFlow render 1 lần
💡 GET /api/tree — endpoint quan trọng nhất
Backend tính toán layout (dagre algorithm) và trả về list nodes + edges đã có tọa độ x/y. Frontend chỉ cần render — không cần tính toán phức tạp ở client. SpouseConnector nodes cũng được tạo tự động ở đây.
